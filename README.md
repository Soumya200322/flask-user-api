# flask-user-api
REST API built with Flask for managing user data using GET, POST, PUT, and DELETE operations.
# Flask User Management REST API

## Objective
Build a REST API using Flask to manage user data.

## Features
- GET all users
- GET user by ID
- POST new user
- PUT update user
- DELETE user

## Technologies
- Python
- Flask
- JSON

## Run

pip install flask

python app.py

Server:
http://127.0.0.1:5000
